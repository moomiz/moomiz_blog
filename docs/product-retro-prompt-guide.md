# 제품 회고 템플릿 · 브리프 작성 가이드

로봇 조작 UI, 테라에듀 등 **직접 만든 제품**을 회고할 때 사용하는 AI 초안 생성 템플릿입니다.

---

## 템플릿이 하는 일

에디터에서 **「제품 회고 (바이브 코딩)」** 을 선택하면, AI에게 **6단계 제품 회고 구조**로 글을 쓰라고 지시합니다.

Tech-Log와 달리 초점은 다음과 같습니다.

| Tech-Log | 제품 회고 |
|----------|-----------|
| 기술 선택·아키텍처 중심 | **제품 맥락** 중심 |
| 일반적인 AI 협업 기록 | **바이브 코딩** 활용 과정 |
| 5단계 | 6단계 (제품 소개 → Why → How → 어려움 → 바이브 코딩 → Takeaway) |

---

## 브리프 양식

에디터 **AI 초안 생성** 패널에 양식이 **기본으로 채워져** 있습니다.  
각 항목만 수정하면 됩니다. (placeholder가 아닌 실제 입력값)

코드: `lib/ai/prompts.ts` → `PRODUCT_RETRO_BRIEF_TEMPLATE`

## 채우기 예시 (로봇 조작 UI)

```
- 제품명: 로봇 조작 UI
- 한 줄 소개: 현장에서 로봇을 실시간으로 조작·모니터링하는 웹 UI
- 만든 기간·역할: 2024.03~06, 프론트 단독
- 기술 스택: React, WebSocket, Zustand, ...
- 핵심 기능: 조이스틱 조작, 상태 대시보드, 알람
- 가장 어려웠던 점: WebSocket 끊김 시 UI 상태 불일치
- 바이브 코딩: Cursor로 패널 레이아웃 초안 생성 → 상태 로직은 직접 작성
- 잘 됐던 점: MVP 2주 내 완성
- 아쉬운 점: 접근성·모바일 대응 미흡
- 다음에 다르게: 연결 복구 로직을 처음부터 설계
```

테라에듀 예시:

```
- 제품명: 테라에듀
- 한 줄 소개: [서비스 한 줄 설명]
- 왜 만들었는지: [문제 / 사용자]
- 어떻게 만들었는지: [스택, 핵심 화면]
- 어려웠던 점: [구체적 에피소드]
- 바이브 코딩: [Cursor에 맡긴 것 / 직접 한 것]
```

**적을수록 AI가 할루시네이션을 덜 합니다.**

---

## AI가 생성하는 글 구조 (6단계)

1. **제품 소개 (What)** — 무엇을, 누구를 위한 제품인지  
2. **왜 만들었는지 (Why)** — 문제 정의, 선택 배경  
3. **어떻게 만들었는지 (How)** — 스택, 아키텍처, 핵심 기능  
4. **어려웠던 점과 극복 (Challenges)** — 원인 → 시도 → 결과  
5. **바이브 코딩 활용기** — `<Prompt>` / `<Response>` + 채택·거절  
6. **회고 및 다음 스텝 (Takeaway)** — 인사이트, 다음 프로젝트 가이드  

---

## 바이브 코딩 섹션 작성 팁

「바이브 코딩」= **방향·맥락을 정한 뒤 AI(Cursor)와 대화하며 빠르게 구현하는 방식**으로 기록합니다.

기록할 때 구분하면 좋습니다.

| 구분 | 예시 |
|------|------|
| AI에 맡긴 것 | 레이아웃, 보일러플레이트, CRUD 초안 |
| 직접 검토한 것 | WebSocket, 권한, 도메인 규칙 |
| 거절한 제안 | Pages Router, localStorage 조회수 등 |

실제 Cursor에 넣었던 프롬프트를 `<Prompt>` 안에 넣으면 블로그 차별화에 좋습니다.

---

## 시스템 프롬프트 요약 (개발 참고)

코드 위치: `lib/ai/prompts.ts` → `PRODUCT_RETRO_STRUCTURE`

- 페르소나: 제품을 만든 풀스택 개발자 + 바이브 코딩 회고 작가  
- 톤: 자랑보다 **과정·판단·실패**  
- 필수: `<Prompt>`, `<Response>` 1회 이상  
- 금지: 브리프에 없는 수치·성능 지어내기 → `[측정 예정]`  

---

## 사용 순서

1. 템플릿: **제품 회고 (바이브 코딩)** 선택  
2. 브리프에 위 항목 채우기  
3. **AI 초안 생성**  
4. 사실·수치 확인 후 수정  
5. (선택) **AI 가독성 최적화**  
6. 발행
